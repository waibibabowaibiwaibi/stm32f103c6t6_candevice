# USB CDC-CAN 文本协议

设备在 USB CDC 虚拟串口上使用基于 ASCII 的 SLCAN 风格协议。它只实现本页列出的帧收发与状态查询，不是完整的 Lawicel SLCAN 实现。

## USB CDC 参数

- 上位机可以继续选择 `921600 8N1`，CDC 固件会接受设置但不会用它改变 USB 速度
- 命令终止符：`\r`；也接受 `\n`

十六进制字符大小写均可输入，设备与上位机输出使用大写。

## USB CDC → CAN

### 标准数据帧

```text
tIIILDD...
```

- `t`：标准数据帧
- `III`：3 位十六进制标识符，范围 `000`～`7FF`
- `L`：DLC，范围 `0`～`8`
- `DD...`：每字节 2 位十六进制，字节数必须等于 DLC

示例：

```text
t12381122334455667788\r
```

### 扩展数据帧

```text
TIIIIIIIILDD...
```

- `T`：扩展数据帧
- `IIIIIIII`：8 位十六进制标识符，有效范围 `00000000`～`1FFFFFFF`

示例：

```text
T001ABCDE3DEADBE\r
```

### 远程帧

标准远程帧使用 `r`，扩展远程帧使用 `R`。远程帧包含 DLC，但不包含数据字节。

```text
r1238\r
R001ABCDE4\r
```

### 状态查询

发送：

```text
V\r
```

设备回复：

```text
V <can_rx> <can_tx> <uart_drop> <cmd_drop> <cmd_bad> <can_tx_drop> <uart_err> <can_recover>\r
```

| 字段 | 含义 |
|---|---|
| `can_rx` | 已转发到 USB CDC 的 CAN 接收帧数 |
| `can_tx` | 已接受并交给 CAN 外设的 USB 命令数 |
| `uart_drop` | USB 发送环形缓冲区满导致的丢弃数；保留旧字段名以兼容上位机 |
| `cmd_drop` | USB 命令队列满或命令过长导致的丢弃数 |
| `cmd_bad` | 以帧字符开头但格式错误的命令数 |
| `can_tx_drop` | 3 个 CAN 发送邮箱均忙导致的丢弃数 |
| `uart_err` | 预留的传输错误计数；保留旧字段名以兼容上位机 |
| `can_recover` | CAN bus-off 成功恢复次数 |

### CAN 波特率查询与设置

查询当前 CAN 波特率：

```text
S?\r
```

设置波特率使用 `S0`～`S8`。编号与常见 SLCAN 波特率编号一致：

| 命令 | CAN 波特率 |
|---|---:|
| `S0` | 10 kbit/s |
| `S1` | 20 kbit/s |
| `S2` | 50 kbit/s |
| `S3` | 100 kbit/s |
| `S4` | 125 kbit/s |
| `S5` | 250 kbit/s |
| `S6` | 500 kbit/s |
| `S7` | 800 kbit/s |
| `S8` | 1000 kbit/s |

设置成功或查询时，设备返回实际值：

```text
S 500000\r
```

设置时固件会停止 bxCAN、重新初始化位时序、恢复接收过滤器与中断，然后重新进入普通 CAN 模式。切换过程中的在途发送可能被中止，短暂到达的报文也可能丢失，因此应先暂停测试流量。设置失败时设备尝试恢复原配置并返回 `E S\r`。设置不会写入 Flash，复位后恢复为 500 kbit/s。

## CAN → USB CDC

收到的 CAN 帧使用与发送命令相同的 `t`、`T`、`r` 或 `R` 格式输出，并以 `\r` 结束。

## 错误行为

- DLC 超出 `0`～`8`、ID 越界、长度不匹配或包含非十六进制字符的帧会被拒绝，并计入 `cmd_bad`
- 非法的 `S` 命令会计入 `cmd_bad`，并返回 `E S`
- 不以 `t`、`T`、`r`、`R`、`V` 或 `S` 开头的输入会被静默忽略
- 设备不会为成功或失败的发送命令返回逐帧 ACK
- `can_tx` 表示固件接受了报文并成功提交给 HAL，不代表总线上有其他节点 ACK
- 上位机的 `TX` 表示文本已加入本机发送队列，不代表单片机已收到，也不代表 CAN 物理层发送成功

## 与标准 SLCAN 的差异

`S0`～`S8` 采用常见 SLCAN 波特率编号，但本协议没有实现典型 SLCAN 的通道打开/关闭、时间戳和序列号命令；`S?`、`S <bitrate>` 与 `E S` 也是本项目扩展。第三方 SLCAN 软件不能被假定为直接兼容；接入前请按本页协议适配。
